01

How to build a week

  1. Open the editor
    Click "Open editor" above. If you've worked on this week before, click Load draft to pick up where you left off.
  2. Set the week date (section 00)
    Pick the Monday of the week. The folder name updates automatically to YYYY-MM-DD.
  3. Fill in the Weekly Overview (section 01)
    Five fields: main campaign focus, key offer, main customer message, primary CTA. Leave fields blank if you're not ready — they'll show as "To confirm" pills on the page.
  4. Fill in Emails 1 and 2 (sections 02 + 03)
    For each email: title, send day + time, segments, subject, preview, then paste the email HTML body. Auto-saves to your browser as you type, so you can close the tab and come back.
    Email HTML: paste the Klaviyo body content (style block + body), no outer shell. Subjects support Klaviyo merge tags like {{ first_name|title }}.
  5. Add website updates (section 04)
    Click Add web change for each one. Title, where it lives, paste the HTML banner code. Add as many as you need this week — most weeks have 1, big weeks have 3.
  6. Drop in the four creatives (section 05)
    Two square (1080×1080) for feed, two vertical (1080×1920) for stories/reels. Drop them in the upload boxes. They'll render in place so you can see them before generating.
    Files: JPG or PNG. Stories must be 1080×1920 to look right on phones.
  7. Preview before generating
    Click Preview in the editor. A new tab opens showing exactly what Matt and Harry will see. If it looks right, close the tab and continue.
  8. Generate the zip
    Click Generate zip. A file called week-YYYY-MM-DD.zip downloads to your Downloads folder.
  9. Drop it into the repo
    Open Terminal and run: cd ~/APPS/meatmerchant-weekly unzip -o ~/Downloads/week-YYYY-MM-DD.zip -d weeks/YYYY-MM-DD/ Replace YYYY-MM-DD with the week's Monday. The -o flag overwrites, the -d flag puts files in the right folder.
  10. Push to GitHub
    git add . git commit -m "Week of [date]" git push Live within ~30 seconds at mellyanncox-ctrl.github.io/meatmerchant-weekly/weeks/YYYY-MM-DD/.
  11. Send Matt and Harry the link
    Drop the link in the WhatsApp group. They review, hit Approve or Add note on each section, you get the email instantly via Web3Forms.
02

When things go wrong

  1. Image not showing on live site
    GitHub Pages is case-sensitive. If the file is CREATIVE-1A.JPG but the page wants creative-1a.jpg, it 404s. Fix: cd ~/APPS/meatmerchant-weekly/weeks/YYYY-MM-DD git mv CREATIVE-1A.JPG creative-1a.jpg git commit -m "lowercase filename" git push Use git mv not plain mv — macOS is case-insensitive locally so plain mv does nothing.
  2. Email iframe shows blank in the preview
    The email HTML you pasted probably has an outer <html> wrapper that conflicts with the iframe. Strip it down to just the style block + body content. Also check that any external image URLs (CDN-hosted, etc.) actually load — broken images render as nothing.
  3. Editor draft is gone
    Drafts live in the browser's localStorage, scoped to the device + browser you used. They survive tab closes and computer restarts, but not browser changes (Chrome → Safari) or clearing site data. If you've lost a draft, regenerate from your notes — there's no recovery.
  4. Pushed but the live site hasn't updated
    GitHub Pages takes 30–60 seconds to rebuild. If still nothing after 2 minutes, check GitHub Actions for a failed deploy or a stuck queue.
  5. Feedback button does nothing on a phone
    Hard-refresh by closing the tab completely and reopening. Mobile browsers cache JS aggressively. If still broken, check the Web3Forms dashboard for failed submissions.
03

How to add an extra email or web change mid-week

  1. Re-open the editor for that week
    Open the editor, set the week date to that Monday, and hit Load draft if your draft is still there. Otherwise you'll need to re-fill the existing fields (or just edit the live weeks/YYYY-MM-DD/index.html directly in your code editor for small changes).
  2. Add the new content
    For an extra web change: hit Add web change and fill in the fields. For an extra email: there's no Email 3 slot in v1 — manually duplicate Email 2's HTML block in the live page or come find me to add Email 3 support.
  3. Generate and replace
    Generate zip, unzip with the same -o overwrite flag into the same folder. Commit + push.
    Heads up: overwriting will replace any manual edits you made directly to the live HTML. Always edit through the editor when possible.
  4. Tell Matt and Harry what changed
    Drop a quick "added [thing] to [section]" message in WhatsApp so they don't have to hunt for the difference.
